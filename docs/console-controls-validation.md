# Проверка управления консолью — 1.1.36

Исправления относятся к клиенту оператора и скрытому Windows-процессу службы.
Для проверки нужны новые приложения на ОБЕИХ сторонах: macOS-оператор и Windows MSI.
Сервер остаётся 0.8.167.

## Найденные дефекты

- Служба отбрасывала `block_input`; теперь BlockInput и SendInput выполняются одним потоком, блокировка снимается при разрыве, истечении lease и остановке потока. Подтверждение отправляется после результата Windows.
- «Ввод текста» использовал запрещённый службе clipboard_set + paste. Теперь text_input вводит UTF-16 напрямую, включая кириллицу, суррогатные пары, Enter и Tab; максимум 4096 UTF-16 единиц.
- Модификаторы Flutter Shift Left/Alt Left и стрелки не совпадали с таблицей Windows. Передаются физические VK-коды; up сохраняет исходный символ down при изменении раскладки.
- Нативная таблица не содержала Win, Win+X, Escape и имени task_mgr из меню. Добавлены также Win+Space, Alt+Shift, Ctrl+Shift.
- Перемещение использовало SetCursorPos; теперь SendInput с абсолютными координатами виртуального рабочего стола. Listener явно принимает указатель на всей области видео.
- Поток ввода запускался до инициализации состояния desktop/клавиш. Запуск перемещён после инициализации всех полей.
- Кнопки масштаба меняли неиспользуемое число. Теперь они меняют матрицу InteractiveViewer; координаты мыши учитывают трансформацию и полосы вокруг видео.
- macOS flutter_webrtc unregisterTexture вызывался под блокировкой copyPixelBuffer. CocoaPods применяет проверяемый патч: освобождение блокировки до unregister, уведомления кадров на main queue. Произвольные таймеры освобождения и уменьшение окна после закрытия убраны.
- Обмен текстовым буфером разрешён службе только после проверки нативным потоком обычного Default desktop. На защищённом экране выводится явная ошибка. Файловые и shell-команды службе не разрешены; в owner-консоли кнопки файлов/чата отсутствуют.

## Проверка на Windows и macOS (ещё не выполнена на реальном удалённом ПК)

1. Закрыть GUI Windows, оставить службу работающей. Подключиться из macOS.
2. Проверить движение, одиночный/двойной левый клик, правый и средний клик, drag, отпускание вне кадра, колесо и кнопки прокрутки.
3. Проверить fit/1:1/+/- и клики после zoom/pan; выбрать каждый монитор, включая монитор с отрицательными координатами и другим DPI.
4. Проверить A–Z, цифры, пунктуацию, кириллицу, обе стороны Shift/Ctrl/Alt/Win, стрелки, Home/End/PageUp/PageDown, Insert/Delete, CapsLock, F1–F12, NumPad. Проверить отпускание при потере фокуса и отключении управления.
5. В меню выполнить Win, Win+R/E/X/D/L, Task Manager, Alt+Tab, Alt+F4, Escape и три способа смены языка. На macOS системные комбинации могут перехватываться самой ОС — использовать кнопки меню.
6. Ввести текст `Привет! Aя 😀`, перенос строки и Tab. Проверить также предел длины и пустой текст.
7. Включить блокировку: физические мышь/клавиатура Windows не работают, удалённые работают. Выключить; повторить с разрывом сети, выходом из сеанса и отключением управления. Ctrl+Alt+Del остаётся аварийным способом снятия блокировки Windows.
8. Проверить отправку/чтение текстового буфера на обычном рабочем столе; на Winlogon/UAC ожидать явный отказ.
9. Проверить режим «только просмотр»: ввод и управление выключены, переключение монитора доступно.
10. Завершить сеанс кнопкой, стрелкой назад и с другой стороны; повторить подключение/выход 10 раз. Окно macOS не уменьшается, домашний экран рисуется, новый сеанс открывается.
