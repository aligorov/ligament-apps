# Консоль ПК — полный план: ввод, файлы, кнопки (2026-10-11)

Основа: верифицированный аудит ввода (5 ревизоров + MS Learn) + инвентаризация UI + матрица 6 конкурентов + WebRTC/Windows-исследование. Эталон тракта мыши = теги v1.1.41/v1.1.42. Файловый P2P-стек `file_*` в продукте уже существует (SOS) и переиспользуется.

Ключевые факты:
- v1.1.44 выкинула рабочий путь мыши: перемещение = только непроверяемый SetCursorPos (мост service_console_bridge.cpp:317-323, GUI input_injector.dart:496-501), двойная инъекция кнопок (:190-198 → одиночный клик = двойной), клип не снимается на MOVE, вся отчётность об ошибках вырезана, утечка HWINSTA на каждое событие.
- MS Learn подтверждает: SetCursorPos требует input-desktop потока (OpenInputDesktop+SetThreadDesktop) И клампится ClipCursor-прямоугольником; UIPI-отказ бесшумный; для SendInput input-desktop-требование не документировано (абсолютный SendInput был устойчивее).
- v1.1.43 имела lease-баг «ввод умер навсегда после Release/истечения».
- Тесты сейчас проверяют мёртвый код (RemotePointerSurface не в дереве; remote_mouse_input_test — неиспользуемый путь).
