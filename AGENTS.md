# Правила сборки и разработки Ligament Apps

## 1. Сборка клиентских приложений (Строгое правило)
- **Все релизные дистрибутивы приложений (Windows MSI, macOS, Linux, Android, iOS)** собираются **СТРОГО В GITHUB ACTIONS**:
  - Workflow: `.github/workflows/build_clients.yml`.
  - Триггер: отправка тега версии `v*` (например, `v1.1.15`).
  - Процесс релиза:
    1. Обновить номер версии в `pubspec.yaml` (например, `version: 1.1.15+41`).
    2. Закоммитить изменения: `git commit -am "..."`.
    3. Создать аннотированный тег: `git tag -a v1.1.15 -m "release v1.1.15: ..."`.
    4. Отправить тег на remote: `git push origin main v1.1.15`.
- Локально на девелоперской машине запускаются только тесты (`flutter test`), анализ (`flutter analyze`) или локальная отладка (`flutter run`).
